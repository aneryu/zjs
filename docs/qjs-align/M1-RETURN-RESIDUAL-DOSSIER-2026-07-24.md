## 刀设计（按 ROI 排序）

1. K1【opCall 单次定价预算】ROI 最高：tryPush*LeafCallFast(inline_calls.zig:1945+) 现在 canEnterInlineCallDepth→commitInlineCallDepth 各自重算 qjsBytecodeFrameAllocaSize（4×ldrh 几何 ×2）+finishFrame 第三次重算窗口；而 *Bytes 变体（vm_call.zig canEnterInlineCallDepthBytes/commitInlineCallDepthBytes，5ede0629 已为 return 侧建好）已存在未被 call 侧使用。改法＝几何一次算入寄存器，准入/提交/Entry.planned_stack_bytes/窗口尺寸全消费同一值（镜像 qjs 17832-17837 alloca_size 单次计算）。预期 −12~18 retired/call（opCall 223→~207）；风险低（纯重定价，语义不变，Debug assert 仍复算对账）；门禁 test262+OOM/checkpoint+ReleaseSafe

2. K4【JSRuntime 热字段重聚簇】cycles 主刀：把 call_depth/native_call_depth/active_bytecode_stack_bytes/两个深度上限/native_stack_limit/vm_stack 标量头(active,chunk_count)/gc.phase 从 18880-25928 散射带聚进低偏移 ≤2 条 cache line（镜像 qjs 热 rt 状态全在头部；旧 zjs ctx+48/56+rt+1032..3336 时代 cyc 1.00x qjs 是直接反证）。预期收回 +13.2 cyc/iter 回归的大半（op_return 时间 29.2→~20，几条 mov #imm 远址物化也消失 −2 retired）；风险＝布局吸引子/Zig 字段桶重排前科（memory 警示），必须交错 A/B cycles + 全量门禁；纯声明序改动不碰语义

3. K6【byteCode() assume-materialized】resolveInlineFunction 已解引用 code（code[0]==check_ctor 检查）证明已物化；op_return republish 的 caller 正在执行中（resume_pc 就是从其 byteCode 导出）物化是不变式。把 4 处 cbnz+重载（op_return 0x125cb44/0x125cb6c 两处、opCall 0x12677e4/0x1267dcc 两处）换 byteCodeAssumeMaterialized+Debug assert。预期 −5 retired/iter+去掉 3.07%/1.78% 两个停顿分支；风险低（gen/async 不走这些臂）

4. K2【准入-提交熔合】把 commitInlineCallDepthBytes 提到 carve 前紧贴准入（同一 rt 寄存器驻留，LLVM 可 CSE），chunk/carve 罕见 miss 走冷 unwind 减回（qjs check-then-alloca 无 unwind 因为检查即承诺——zjs 镜像为提交即承诺+冷撤销）。预期 −4~6 retired/call（杀掉 rt 第 3、4 次重载）；风险中（miss 路径 errdefer 平衡，需 OOM 压测）

5. K3【popReturned* rt 穿线】popReturnedEmptyLeaf(inline_calls.zig:2936)：deinitEmptyLeafInline 已算 rt，leaveInlineCallDepthBytes(self.ctx,...) 又 ctx→runtime 重载（0x125cb08-0c 两条串行载，arena store 别名挡 CSE）。签名改传 rt。预期 −2~3 retired + 缩短 return 关键串行链（cycles 加成）；风险极低

6. K7【poll error-union 标量化】opCall poll 快路径残留 rodata error-union 幻影（adrp __anon_129696+ldrb[+4]+cbnz+ldr[x8] 分支合流指针 phi，0x1267828/1267900）：pollInterrupt 的 !void 结果没保持寄存器标量。重构为 handler 内直接 tick 分支+冷函数 throwInterrupted 返回 Outcome（M-EMIT 无帧 per-op 先例形态）。预期 −4~5 retired/call；风险低中，落地判据＝反汇编确认 phi 消失（insn 幻影判别纪律）

7. K8【resolve 检查重排】callable 类别改单值 cmp class_id==bytecode_function 快臂优先（本形态 100% 命中），位掩码集降为冷臂；captureSlice 的 csel 物化推迟到 O1/O2 消费臂（空叶臂不读 captures）。预期 −6~8 retired/call；风险中：resolveInlineFunction 被全部 call 形态共享，动前须逐形态 A/B（热臂绝不共享纪律）

8. K9【op_return prologue 瘦身】最后做：空叶臂只需 ~4 对 callee-saved，但同函数挂着 O1/O3/general 冷臂逼出 6 对 stp+0xc0 帧（15 insn 出入账）。外联非空叶家族为独立 pinned 符号可省 ~6 retired，但 O1 对 fib 家族是热臂、align(64) pin 群+2.4% cyc 翻覆前科＝高布局风险，仅在 K4 落地后带 cycles 门禁试刀

9. 【反刀警示】①不要恢复 e73e8a0c 的 inc 发码：qjs 实测同发 post_inc+put_loc_check+drop（其 inc_loc 熔合 35407 只认 OP_put_loc），旧 inc 是不忠实偏离被正确修正，~13-15 retired/iter 是忠实税 qjs 同样在付；②中断 poll 与字节预算账本不可删（qjs 17787 同位机制/OOM-栈溢出忠实语义），只能重定价（K7/K1/K2/K4）；③全部预期叠加 ≈−35~45 retired/call + −6~10 cyc/iter，投影回到 ~1.06-1.08x insn、~1.05x cyc，剩余为堆帧 Machine 相对 qjs alloca 的结构常数

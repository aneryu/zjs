# 18 — test262 runner（`src/cli/run_test262*.zig`）

`run-test262` / `test-runner` 共用 `run_test262.zig` 为根，跟随 `-Doptimize`。worker 用原子下标抢测；reporter 用一把 mutex 串 stderr 与聚合。每 worker 一条 arena（`reset(.retain_capacity)`），避免每测 munmap。

`$262.agent` 与 host 钩子见本文件后半与主册。

## 文件级类型

### `run_test262_options.zig`

`usage` 字符串（现已列出 `parse` 实际支持的 `-v` / `-vv`）。`Error = Usage | MissingValue | TooManyItems`。`Config`：config 路径、test_root、module、verbose、update_errors、timeout、threads（0=CPU 数）、known_error_file、reports_dir、engine_path、feature_overrides、start/stop index、files/dirs（各最多 64）。`FeatureOverrideKind` enable/skip。`BoundedFeatureOverrides` / `BoundedList` 固定数组。

### `run_test262_names.zig`

`NameList`：拥有字符串与 backing；`items` 是 `[]const []const u8`，写入时 `@constCast`。`capacity` 与 `items.len` 分离，空表 `deinit` 不 free。

### `run_test262_config.zig`

`LoadedConfig`：testdir/harnessdir/errorfile + excludes/reincludes/enabled_features/skipped_features 四个 `NameList`。`[tests]` 段忽略。

### `run_test262_metadata.zig`

`NegativeMetadata{phase, type_name}`。`TestMetadata`：includes/features/flags + optional negative。

### `run_test262_source.zig`

`HarnessCache.Entry{name, bytes}`。`Test262Override{path, upstream_commit, upstream_sha256, reason}`。`override_manifest` 五条钉死的本地覆盖（TypedArray slice / BigInt Set / 三条 sm Error）。`PathError = Test262PathOutsideRoot`。

### `run_test262_reporter.zig`

`TestRunResult = passed | failed | skipped`。`Reporter.Bucket`：syntax/type/test262/range/reference/unhandled_promise_rejection/other/empty。`DirEntry` / `SkippedFeatureEntry`。一把 `std.Io.Mutex`。

### `run_test262.zig`

`SelectionSummary` / `PreparedSelection` / `ExecutionSummary`。`WorkerShared`（跨线程只碰 `next_index` 与 reporter）。`WorkerThreadContext`。`stderr_storage_len = 2048`。

### `run_test262_host.zig`

`Test262Agent{source, owner_runtime, agent_runtime, broadcast_buffer, done, thread_done}`。`Test262AgentReportEntry{owner_runtime, bytes}`。`Test262AgentCoordinator` 进程级。`threadlocal current_test262_agent`。`test262_gpa`：thread-safe、retain_metadata、关 safety 的 DebugAllocator。`VerifyFlag`。

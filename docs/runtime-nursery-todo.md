## 评估范围

- 比较当前复制式 nursery 与基线回收路径的吞吐、GC 暂停、峰值及稳态内存。
- 覆盖大量短命对象、高存活率、长期运行及跨代引用密集的负载。
- 核算写屏障、存活对象复制与晋升、保守根导致的 pin 和整页保留成本。
- 查明当前默认配置、实际进入的分配/回收路径及对象覆盖范围，避免只凭模块存在推断启用状态。
- 根据证据决定是否采用当前实现、默认启用，以及容量和晋升策略；参数不预先定案。

## Decision (per the ruling's criteria)

T(Cc) ≈ 0 (in-noise / slightly positive) → the first GO condition
("S1-C 在噪声内或正向") is met directly; independently B ≈ 3% ≥ 2×T with
overwhelming margin. **Formal P2-S1 is approved to proceed with the Cc
carry-capacity ownership shape** (installCodeWithCapacity /
installAtomOperandsWithCapacity, full-backing frees). Constraints per the
ruling §5: delete the sizing walk in ReleaseFast, no per-instruction
records, single-pass emit with immediate lowering actions, single-row
scope-var plan compute-and-consume, growable/upper-bounded jump sites,
R1T relocation untouched, input Bytecode immutable until the no-fail
commit, old sizing pass retained as the Debug/ReleaseSafe oracle
(comparing exact sizes, atom counts, jump counts, scope plans, and final
byte identity).
